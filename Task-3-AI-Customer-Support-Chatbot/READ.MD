# 💬 AI Customer Support Chatbot

An AI-powered customer support chatbot built with **Python, Streamlit, LangChain, and Google Gemini**.

The application generates professional customer support responses based **only on the provided support policy**, helping prevent the model from inventing unsupported information.

---

## 🚀 Features

- 💬 Customer question input
- 📋 Custom support policy input
- 🤖 Google Gemini-powered responses
- 🔗 LangChain integration
- 🛡️ Policy-based response generation
- 🚫 Prevents unsupported policy assumptions
- ⚡ Interactive Streamlit interface
- 🎨 Custom dark-themed UI
- ❌ Handles missing API key and runtime errors

---

## 🛠️ Technologies Used

- **Python**
- **Streamlit**
- **LangChain**
- **Google Gemini**
- **python-dotenv**
